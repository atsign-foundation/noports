Instructions

  1. Select your board above.
  2. Plug the device into this computer via USB.
  3. Hold the BOOT button on the back of the board, click Connect & Flash, select the serial port, then release BOOT.
  4. Wait for the flash to complete (~30–60 s).
  5. Follow the on-screen setup wizard on the device display after a factory reset, or resume normal use after an upgrade.

Troubleshooting

  1. "Failed to initialize" — hold the BOOT button on the back of the board before clicking Connect & Flash, then release after selecting the port.
  2. Device stuck in a boot loop (screen blank / resets every few seconds) — use the Erase device option inside the flash dialog, then flash using the BOOT-button method.
  3. No serial port appears — try a different USB cable (some are charge-only), or close any other app using the port (Arduino IDE, PlatformIO monitor).
  4. CrowPanel Advance on macOS: no serial port — its CH340K USB chip is not covered by the built-in Apple driver. Install the WCH CH34x driver, approve it under System Settings → Login Items & Extensions → Driver Extensions, then reconnect. Windows and Linux need no driver.
